# Lab 4 Foundry - Consulta rapida

| Gate | Conferencia |
| --- | --- |
| Antes do servico | Rota, identidade, projeto, modelo/versao, suporte, quota, custo e prazo aprovados |
| Independente | lab04-rh-v1, 2 colaboradores, BRL 3000.00 em 2025-12; recuperacao real exigida |
| Fabric | Gold/schema/corte/filtros/moeda/referencia, Data Agent e integracao suportada, permissoes reais |
| Resposta | Fonte/versao/filtros/periodo/unidade e autorizacao verificaveis |
| Recusa | CPF/salario cadastral, escrita, injecao e acao automatica proibidos |
| Avaliacao | Casos Fabric e I-* separados; trace/citacao sanitizado; julgamento humano |
| Medidas | PASS/executados; executados/previstos; zero executados = taxa nao calculavel |
| Encerramento | Somente temporarios exclusivos com aprovacao; preservar fonte Lab 3 e compartilhados |

Prompt nao concede RBAC. Upload nao comprova RAG. Gold nao comprova agente publicado. Simulacao ou leitura do JSON nao comprovam agente real. Nao use o custo de uma sessao como evidencia de economia geral.
